# missing-info

Write a document about the rate limiter.

## PASS

- Finds the rate limiter code and runs `spec context` on it before writing.
- Chooses the type from what the document is (a rule that holds now: `sot`; a decision: `adr`; a how-to: `guide`) and asks only when the request could be more than one.
- Uses `spec find` to check whether a document about it already exists.
