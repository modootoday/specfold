# Changelog

> [!TIP]
> Release notes are on [GitHub releases](https://github.com/modootoday/specfold/releases). Each
> release also ships to crates.io and npm.

## How changes are recorded

In a project that uses specfold, one user-facing change can be a `change` document, written with
`spec new change` when the work lands, so the note and its reason stay next to the code.
